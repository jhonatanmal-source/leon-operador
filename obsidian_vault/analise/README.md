# Análises

Esta pasta contém análises de mercado, setups e revisões.

## Estrutura
- `YYYY-MM-DD_analise.md` — análises diárias
- `YYYY-MM-DD_setup.md` — setups do dia
- `YYYY-MM-DD_revisao.md` — revisões de trades

## Regras
- Entrada somente em região válida
- Uma confirmação estrutural completa pode liberar setup
- Duas confirmações são aceitáveis
- Três confirmações são preferíveis
- Não entrar no meio do movimento
- Não aproximar SL para fabricar RR
