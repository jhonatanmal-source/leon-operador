# Aprendizados Diários — LEON XAU ELITE AI

Este diretório contém o sistema de aprendizado diário do LEON.

## Estrutura

- `CONTEXTO_EVOLUCAO.md` — compilado dos aprendizados mais relevantes
- `INDICE.md` — índice de todas as entradas
- `YYYY-MM-DD.md` — aprendizados do dia

## Sincronização

Este diretório é sincronizado com o vault Obsidian em `obsidian_vault/aprendizados_diarios/`.

Use o script `scripts/sync_obsidian_vault.sh` para sincronizar:

```bash
./scripts/sync_obsidian_vault.sh          # sincroniza
./scripts/sync_obsidian_vault.sh status   # verifica status
```

## Regras

- Não armazenar credenciais, tokens ou senhas
- Não armazenar números de conta real
- Não armazenar informações pessoais
